# Finance Expense Dashboard

Power BI Desktop-da hazırlanmış birsəhifəlik hesabat. Büdcə gəlirini, xərcləri və büdcə mənfəətini izləmək, həmçinin məhsul kateqoriyaları üzrə faktiki mənfəəti büdcə ilə müqayisə etmək üçün istifadə olunur.

## Hesabatda nəyi araşdırmaq olar?

| Biznes sualı | Hesabatdakı görünüş |
| --- | --- |
| Büdcə gəliri və büdcə mənfəəti aylar üzrə necə dəyişir? | Aylıq sütun və xətt qrafiki |
| Şöbələr üzrə maliyyə göstəriciləri necə fərqlənir? | Büdcə mənfəəti üzrə çubuq qrafiki və gəlir, xərc, mənfəət cədvəli |
| Faktiki mənfəət büdcə ilə müqayisədə necədir? | Məhsul kateqoriyaları üzrə müqayisə |
| Ümumi xərclərin hansı hissəsi hər kateqoriyaya düşür? | Kateqoriyaların faiz payını göstərən dairəvi diaqram |
| Büdcə mənfəətinə görə ilk beş müştəri kimdir? | Müştərilər üzrə ilk beşliyi göstərən çubuq qrafiki |

Yuxarıdakı kartlarda büdcə gəliri, xərclər, büdcə mənfəəti və müştəri məmnuniyyəti göstəriciləri göstərilir. Hesabatı **Month** (ay) və **Region** (region) filtrləri ilə araşdırmaq olar.

## Məlumat və göstəricilər

Vizualizasiyalar Power BI modelindəki `Table Data` cədvəlinə əsaslanır. Gəlir və mənfəət kartlarında müvafiq olaraq `Budget Revenue` və `Budget Profit` sahələri cəmlənir. `Actual Profit` sahəsi məhsul kateqoriyaları üzrə büdcə ilə müqayisədə istifadə olunur.

## Hesabatı necə açmaq olar?

1. [Finance Expense Dashboard.pbix](Finance%20Expense%20Dashboard.pbix) faylını repozitoriyadan endirin.
2. Faylı **Microsoft Power BI Desktop** proqramında açın və **Dashboard** səhifəsinə keçin.
3. Bütün ayların trendini görmək üçün **Month** filtrində saxlanmış `Apr` seçimini təmizləyin. Konkret dövr və region üzrə nəticələrə baxmaq üçün uyğun filtrləri seçin.
